Project Overview

A pathfinding project I built in college in C++, where an AI-controlled ghost chases the player through a maze using the A* algorithm. I built it to really understand how pathfinding works, so instead of using a library, I implemented A* from scratch, along with the node graph and steering behaviors it runs on.

Key Features

  • A* pathfinding implemented from scratch in C++
  • A node-graph system representing the maze for the algorithm to search
  • Steering behaviors (seek, pursue, follow-path) driving the AI
  • A hand-written math library for the vector and matrix math
  • Rendered with raylib

Development Details

  • Language: C++
  • Library: raylib (graphics)
  • Status: Completed
  • Platforms: Windows

What I worked on

I built this in college to actually understand pathfinding instead of just using something prebuilt, so I wrote the whole thing in C++ from the ground up. What I built:

  • The A* algorithm itself, an open and closed list, sorting nodes by their f-score to always explore the cheapest path first, then tracing back through parent nodes to build the final route
  • A node graph representing the maze that the algorithm searches across
  • Steering behaviors (seek, pursue, and path-following) that move the ghost along the path A* finds
  • A math library I wrote myself for the vectors and matrices everything is built on

Development Insights

This is the project I'm proudest of on the fundamentals side. Implementing A* from scratch, not calling a library, but actually building the open and closed lists and the scoring myself, taught me how pathfinding really works under the hood. Writing my own math library and the node graph underneath it pushed my C++ and my understanding of data structures a lot further. It's the project that made algorithms click for me.
