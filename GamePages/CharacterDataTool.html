Character Data Tool
A Deep Dive

A tool I developed for managing JSON data in .NET. You can create, edit, and delete character entries.

Project Overview

Character Data Tool is a command-line program I built in .NET (C#) for managing character data stored in JSON. From a simple text menu, you can view all your characters and add, edit, or delete them, and every change is saved straight back to the JSON file. I made it to teach myself how to work with JSON and file storage in C#.

Key Features

  • Add, edit, and delete character entries from a simple menu
  • Reads and writes JSON, so all your changes are saved to disk
  • Input handling for bad entries, invalid numbers, and empty fields

Development Details

  • Type: Command-line application

What I worked on

A solo project to get comfortable with JSON and file handling in C#, before I moved on to building an actual API. What I built:

  • Loading character data from a JSON file into C# objects, and writing it back out so changes stick
  • A menu loop for adding, editing, and deleting characters
  • Validation for the things users get wrong, missing files, non-number input, empty fields, and out-of-range choices

Development Insights

This was one of my first steps into .NET outside of game engines. It's simple on the surface, a console app, but it's where I got comfortable reading and writing JSON and handling all the ways user input can go wrong. It's also what led directly into my Character Vault API project, where I took the same ideas and built them into a proper REST backend.
