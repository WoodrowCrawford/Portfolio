Inventory System Prototype
A Deep Dive

A small prototype made in Unreal Engine to demonstrate a basic inventory system.

Project Overview

A prototype I built in Unreal Engine during college to learn how to architect an inventory system in C++. The player can pick up items, store them in a limited inventory, and use them, and I focused on structuring it properly, with C++ handling the logic and Blueprints handling the items and UI on top.

Key Features

  • Pick up, store, and use items, with a capacity limit
  • An abstract item base class that specific items (like food that heals you) build on
  • An inventory built as a reusable component any actor can have
  • A UI that updates itself whenever the inventory changes
  • Designer-friendly, new items can be made in Blueprints without touching code

Development Details

  • Engine: Unreal Engine
  • Language: C++ (with Blueprints for items and UI)
  • Status: Completed
  • Platforms: Windows

What I worked on

A solo college prototype where the point was learning to structure an inventory the way a real Unreal project would, not just make one that works. What I built:

  • An abstract item base class with a virtual Use function, so different item types (like food that heals you) can define their own behavior
  • The inventory as a component, with add, remove, and a capacity limit, so it can be dropped onto any actor
  • An event that fires whenever the inventory changes, which the Blueprint UI listens to so it updates on its own
  • Item definitions exposed to the editor, so new items can be created in Blueprints without writing more C++

Development Insights

This was me learning how Unreal projects are actually structured in C++. The interesting part wasn't the inventory working, it was designing it well, using an abstract base class for items, building the inventory as a reusable component, and firing an event to keep the UI in sync instead of hard-wiring it. It taught me a lot about inheritance, components, and how C++ and Blueprints are meant to work together in Unreal.
